# Guide Builder (Airtable Interface extension)

Builds branded panel interview guides inside TA Airtable. A CES picks a requisition,
chooses competencies and questions, and clicks Generate; the extension builds a Word
file and attaches it to an **Interview Guides** record linked to the requisition.
Design: `docs/superpowers/specs/2026-10-14-airtable-guide-builder-design.md`.

## Tables

| Table | Used for | Extension access |
|---|---|---|
| Master Tracker - All TA | Requisitions to build guides for | read only |
| Interview Guides | One record per guide (round, panelists, picks, file) | read, create, edit |
| Competencies | Question bank: one row per competency | read only |
| Interview Questions | Question bank: one row per question, linked to its competency | read only |

The extension never writes Master Tracker, **Panel Interview Guide** or **Panel Interview
Guide Questions**. Field names are in `frontend/lib/airtableData.js`; renaming a field
there or in Airtable breaks the extension until both match.

## Interface page settings

The extension sees only what its page's properties panel shows it. On the Custom page:

1. **Data → Tables:** add all four tables above.
2. **Data → Fields** (per table; Airtable shows only the first 4 fields by default):
   - Master Tracker - All TA: Position Title, Req #, Brand, Hiring Manager,
     Panel Interview Format, #of Panelists
   - Interview Guides: all fields (Guide Name, Requisition, Interview Round, Panelists,
     Selections, Guide File, Last Generated, Generated By)
   - Competencies: Name, Group, Active
   - Interview Questions: Question, Competency, Order, Active
3. **User actions:** turn on **Edit records inline** and **Add records inline** for
   Interview Guides only. Leave them off for the other three tables so the question bank
   and Master Tracker stay read-only from the page.

Don't filter the Interview Guides data on this page. The extension looks up a guide it
just created, and a filter that hides it shows "That guide no longer exists."

## Editing the question bank

TA edits questions in the Airtable tables; there is no code change or release.

- **Edit a question:** change its **Question** text in Interview Questions.
- **Add a question:** add a row in Interview Questions, link it to a competency, and set
  **Order** (lower numbers appear first) and tick **Active**.
- **Retire a question or competency:** untick **Active**. Don't delete rows; guides
  already generated keep the old text, and reopening one shows a retired or reworded
  question as a custom question so nothing is lost.
- **Add a competency:** add a row in Competencies with **Name**, **Group** and
  **Active**, then link its questions to it.

Changes appear the next time a CES opens the page.

## Develop and release

Needs `@airtable/blocks-cli@3.0.3` installed globally and a `block:manage` personal access
token set with `block set-api-key` (stored in `~/.config/.airtableblocksrc.json`; never
commit it).

```bash
npm install
npm test               # or: npm run coverage
block run              # serves https://localhost:9000; accept the self-signed cert once
```

To try a dev build, open the Interface page in editor mode, select the extension and
click **Develop**. Develop mode turns off on every page reload. The first click into the
extension only focuses it.

```bash
block release                 # sandbox (remote in .block/remote.json)
block release --remote live   # TA Airtable - Live, once that remote is added
```

A released build runs for everyone on the page with Develop off.

- SDK pinned to `@airtable/blocks@0.0.0-experimental-3c2a2d775-20260807` (pre-release),
  React 19.3.0. Upgrading is a deliberate task: re-run the sandbox checks in
  `docs/superpowers/spikes/2026-10-airtable-interface-spike.md`.
- Brand logos are copied from `../index.html` by `npm run extract` (it also refreshes the
  test-only copy of the old question bank). Only needed if the logos change.
- File drop: `FILE_DROP_URL` in `frontend/config.js` (Render service
  `interview-guide-file-drop`; see `../file-drop/README.md`). The free tier sleeps, so the
  first Generate after a quiet spell can take about a minute. If the drop is down, the
  extension offers a direct **Download .docx** instead.
- No Airtable token belongs in the extension, the base, this repo or the file drop.
