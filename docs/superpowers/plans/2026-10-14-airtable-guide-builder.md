# Airtable Interview Guide Builder Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let CES build branded `.docx` interview guides on a full-page Airtable Interface extension in TA Airtable - Live, attached to a new Interview Guides table linked to requisitions.

**Architecture:** A React Interface extension (pinned pre-release `@airtable/blocks` SDK) with a New Guide–first start screen and a builder screen. All logic lives in small pure modules under `airtable-extension/frontend/lib/` (question bank, brand mapping, selections, validation, document builder, file-drop client), so it can be unit-tested without Airtable. The `.docx` is built in the browser, POSTed to a tiny token-free Node "file drop" on Render's free tier, and the returned short-lived URL is written to the attachment field using the CES's own permissions.

**Tech Stack:** JavaScript (ES modules) + JSDoc, React 19.3.0, `@airtable/blocks@0.0.0-experimental-3c2a2d775-20260807`, `docx@9.7.2`, Vitest 5.0.2 (+ jsdom 30.1.1, @testing-library/react 16.3.3, jszip 3.10.2 for tests), Node 22+ `node:http` for the file drop, Render (free web service).

**Spec:** `docs/superpowers/specs/2026-10-14-airtable-guide-builder-design.md`

## Global Constraints

- Never modify existing Master Tracker fields, interfaces or automations. The only Master Tracker change is the reverse link field Airtable creates for **Interview Guides**. **Panel Interview Guide** and **Panel Interview Guide Questions** are never written.
- No Airtable token is stored in the extension, the base, the repo or the file drop.
- Pin `@airtable/blocks` exactly to `0.0.0-experimental-3c2a2d775-20260807` (no `^` or `~`). All other dependencies are pinned exactly too.
- Users work only in Interfaces. Nothing may require the base's grid or data view.
- Build and test in a sandbox base first. Nothing is added to TA Airtable - Live (`appdEzbaGnO9Aru66`) until Task 13's go-live gate is signed off by Scott.
- Blank Brand → Columbia template. Unrecognized Brand → CES chooses from a dropdown; choice saved in `brandOverride`.
- File drop: `.docx` only (`application/vnd.openxmlformats-officedocument.wordprocessingml.document`), ≤ 5 MB, random ≥ 128-bit IDs, expires 10 minutes after upload, memory only, never logs file contents, holds no secrets.
- Generating again **appends** a file to Guide File; never delete older files.
- Selections are saved **before** the `.docx` is built.
- Retail guides, per-candidate guides, auto-sending and editing the question bank in Airtable are out of scope.
- Exact table and field names (Master Tracker): `Master Tracker - All TA`; `Position Title`, `Req #`, `Brand`, `Hiring Manager`, `Panel Interview Format`, `#of Panelists` (no space after `#`).
- Exact table and field names (new): `Interview Guides`; `Guide Name`, `Requisition`, `Interview Round` (Panel, Second Panel, Final, Other), `Panelists`, `Selections`, `Guide File`, `Last Generated`, `Generated By`.
- Coverage ≥ 80% for `airtable-extension/frontend/lib/` and `file-drop/src/`.
- Code style: immutable updates (return new objects/arrays), functions < 50 lines, files < 400 lines, no `console.log` left in shipped code.

## Review Focus

These are failure modes the spec implies but doesn't spell out. Each has a test in the task named.

1. **A panelist is removed after competencies were assigned to them.** Generate must be blocked with "<competency>: assign a panelist." rather than producing a guide naming someone who isn't on the panel. (Task 6, `validation.test.js`)
2. **The Selections cell is hand-edited, truncated or from an unknown version.** The builder must open with empty picks and a visible "reset" warning, not crash. (Task 6, `selections.test.js`)
3. **The CES double-clicks Generate.** Only one save, upload and attachment happens. (Task 11, `BuilderScreen.test.jsx`)
4. **Position Title contains `/`, `:`, `"` or is very long.** The file name stays valid and readable. (Task 7, `fileName.test.js`)
5. **Question or custom question text contains `&`, `<` or smart quotes.** The `.docx` opens and the text is unchanged. (Task 8, `docBuilder.test.js`)

`file-drop/src/store.js`:
```js
import {randomBytes} from 'node:crypto';

const TEN_MINUTES_MS = 10 * 60 * 1000;

/**
 * In-memory file store whose entries expire. Nothing is written to disk.
 * @param {{ttlMs?: number, now?: () => number}} [options]
 */
export function createStore({ttlMs = TEN_MINUTES_MS, now = () => Date.now()} = {}) {
  let entries = new Map();

  function sweep() {
    const t = now();
    entries = new Map([...entries].filter(([, entry]) => entry.expiresAt > t));
  }

  return {
    put(bytes, filename) {
      sweep();
      const id = randomBytes(16).toString('hex');
      entries = new Map(entries).set(id, {bytes, filename, expiresAt: now() + ttlMs});
      return id;
    },
    get(id) {
      sweep();
      return entries.get(id) ?? null;
    },
    size() {
      sweep();
      return entries.size;
    },
  };
}
```

`file-drop/src/app.js`:
```js
export const DOCX_TYPE =
  'application/vnd.openxmlformats-officedocument.wordprocessingml.document';

const ID_PATTERN = /^[a-f0-9]{32}$/;
const MAX_FILENAME_LENGTH = 200;
const ZIP_MAGIC = [0x50, 0x4b, 0x03, 0x04];

function send(res, status, body, headers = {}) {
  const isJson = body !== undefined && !(body instanceof Uint8Array);
  res.writeHead(status, {
    ...(isJson ? {'Content-Type': 'application/json'} : {}),
    ...headers,
  });
  res.end(isJson ? JSON.stringify(body) : body);
}

function corsHeaders(req, allowedOrigin) {
  const origin = req.headers.origin;
  if (!origin || !allowedOrigin.test(origin)) return {};
  return {
    'Access-Control-Allow-Origin': origin,
    'Access-Control-Allow-Methods': 'GET, POST, OPTIONS',
    'Access-Control-Allow-Headers': 'Content-Type',
    Vary: 'Origin',
  };
}

function isValidFilename(name) {
  return (
    typeof name === 'string' &&
    name.length <= MAX_FILENAME_LENGTH &&
    name.toLowerCase().endsWith('.docx')
  );
}

// Reads the whole body but stops keeping bytes past maxBytes, so the client still
// receives the 413 response instead of a reset connection.
function readBody(req, maxBytes) {
  return new Promise((resolve, reject) => {
    const chunks = [];
    let total = 0;
    req.on('data', (chunk) => {
      total += chunk.length;
      if (total <= maxBytes) chunks.push(chunk);
    });
    req.on('end', () => {
      if (total > maxBytes) reject(Object.assign(new Error('too large'), {status: 413}));
      else resolve(new Uint8Array(Buffer.concat(chunks)));
    });
    req.on('error', reject);
  });
}

function startsWithZipMagic(bytes) {
  return ZIP_MAGIC.every((b, i) => bytes[i] === b);
}

async function handleUpload(req, res, url, ctx) {
  const cors = corsHeaders(req, ctx.allowedOrigin);
  if (!cors['Access-Control-Allow-Origin']) return send(res, 403, {error: 'origin not allowed'});
  const filename = url.searchParams.get('filename');
  if (!isValidFilename(filename)) return send(res, 400, {error: 'filename must end in .docx'}, cors);
  if (req.headers['content-type'] !== DOCX_TYPE) return send(res, 400, {error: 'docx only'}, cors);
  try {
    const bytes = await readBody(req, ctx.maxBytes);
    if (!startsWithZipMagic(bytes)) return send(res, 400, {error: 'not a docx file'}, cors);
    const id = ctx.store.put(bytes, filename);
    return send(res, 201, {url: `${ctx.publicBaseUrl}/files/${id}`}, cors);
  } catch (err) {
    return send(res, err.status === 413 ? 413 : 400, {error: err.status === 413 ? 'file too large' : 'bad upload'}, cors);
  }
}

function handleDownload(res, id, store) {
  const entry = ID_PATTERN.test(id) ? store.get(id) : null;
  if (!entry) return send(res, 404, {error: 'not found'});
  const safeName = entry.filename.replace(/["\r\n]/g, '').replace(/\s+/g, ' ');
  return send(res, 200, entry.bytes, {
    'Content-Type': DOCX_TYPE,
    'Content-Disposition': `attachment; filename="${safeName}"`,
    'Cache-Control': 'no-store',
  });
}

/**
 * @param {{store: ReturnType<import('./store.js').createStore>, allowedOrigin: RegExp,
 *          maxBytes: number, publicBaseUrl: string}} ctx
 */
export function createApp(ctx) {
  return (req, res) => {
    const url = new URL(req.url, 'http://localhost');
    const parts = url.pathname.split('/').filter(Boolean);
    if (req.method === 'OPTIONS') return send(res, 204, undefined, corsHeaders(req, ctx.allowedOrigin));
    if (req.method === 'GET' && url.pathname === '/health') {
      return send(res, 200, {ok: true}, corsHeaders(req, ctx.allowedOrigin));
    }
    if (req.method === 'POST' && url.pathname === '/files') return handleUpload(req, res, url, ctx);
    if (req.method === 'GET' && parts.length === 2 && parts[0] === 'files') {
      return handleDownload(res, parts[1], ctx.store);
    }
    return send(res, 404, {error: 'not found'});
  };
}
```

import {createStore} from './store.js';
import {createApp} from './app.js';

const DEFAULT_ORIGIN_PATTERN = '^https://([a-z0-9-]+\\.)*airtableblocks\\.com$|^https://localhost:9000$';
const FIVE_MB = 5 * 1024 * 1024;

const publicBaseUrl = process.env.PUBLIC_BASE_URL ?? process.env.RENDER_EXTERNAL_URL;
if (!publicBaseUrl) {
  throw new Error('Set PUBLIC_BASE_URL (Render sets RENDER_EXTERNAL_URL automatically).');
}

const app = createApp({
  store: createStore(),
  allowedOrigin: new RegExp(process.env.ALLOWED_ORIGIN_PATTERN ?? DEFAULT_ORIGIN_PATTERN),
  maxBytes: FIVE_MB,
  publicBaseUrl: publicBaseUrl.replace(/\/$/, ''),
});

const port = Number(process.env.PORT ?? 10000);
createServer(app).listen(port, () => {
  process.stdout.write(`file-drop listening on ${port}\n`);
});

// Copies the question bank and brand logos out of the web app (../index.html) so the
// extension uses identical content. Re-run after editing QBANK in index.html.
import {readFileSync, writeFileSync, mkdirSync} from 'node:fs';
import vm from 'node:vm';

const html = readFileSync(new URL('../../index.html', import.meta.url), 'utf8');
const outDir = new URL('../frontend/lib/data/', import.meta.url);

function arrayLiteralAfter(source, marker) {
  const start = source.indexOf(marker);
  if (start < 0) throw new Error(`Marker not found: ${marker}`);
  const open = source.indexOf('[', start);
  const close = source.indexOf('\n];', open);
  if (close < 0) throw new Error(`End of array not found after: ${marker}`);
  return source.slice(open, close + 2);
}

function logo(name) {
  const match = html.match(new RegExp(`const ${name}_B64 = '([A-Za-z0-9+/=]+)'`));
  if (!match) throw new Error(`Logo not found: ${name}`);
  return match[1];
}

const qbank = vm.runInNewContext(arrayLiteralAfter(html, 'const QBANK = ['));
const logos = {
  columbia: {base64: logo('COLUMBIA'), width: 140, height: 35},
  sorel: {base64: logo('SOREL'), width: 160, height: 40},
  mountainhardwear: {base64: logo('MHW'), width: 200, height: 45},
  prana: {base64: logo('PRANA'), width: 160, height: 40},
};

const header = '// GENERATED by scripts/extract-web-app-data.mjs from ../index.html. Do not edit.\n';
mkdirSync(outDir, {recursive: true});
writeFileSync(new URL('questionBank.data.js', outDir), `${header}export const QBANK = ${JSON.stringify(qbank, null, 2)};\n`);
writeFileSync(new URL('logos.data.js', outDir), `${header}export const LOGOS = ${JSON.stringify(logos)};\n`);
process.stdout.write(`Wrote ${qbank.length} questions and ${Object.keys(logos).length} logos.\n`);

import {QBANK} from './data/questionBank.data.js';

export {QBANK};
export const LEADERSHIP_GROUP = 'Leadership Capabilities';
export const BEHAVIORAL_GROUP = 'Behavioral Skills';

const namesIn = (group) =>
  [...new Set(QBANK.filter((q) => q.group === group).map((q) => q.competency))].sort();

export const LEADERSHIP = namesIn(LEADERSHIP_GROUP);
export const BEHAVIORAL = namesIn(BEHAVIORAL_GROUP);

export function questionsFor(competency) {
  return QBANK.filter((q) => q.competency === competency).map((q) => q.question);
}

export function groupOf(competency) {
  return QBANK.find((q) => q.competency === competency)?.group ?? '';
}

export function isKnownQuestion(competency, text) {
  return questionsFor(competency).includes(text);
}

export const BRANDS = [
  {key: 'columbia', label: 'Columbia Sportswear'},
  {key: 'sorel', label: 'SOREL'},
  {key: 'mountainhardwear', label: 'Mountain Hardwear'},
  {key: 'prana', label: 'prAna'},
];

const ALIASES = {
  csc: 'columbia',
  columbia: 'columbia',
  'columbia sportswear company': 'columbia',
  mhw: 'mountainhardwear',
  'mountain hardwear': 'mountainhardwear',
  prana: 'prana',
  sorel: 'sorel',
};

/** Blank → Columbia (default); unknown → null. */
export function mapBrand(value) {
  const normalized = (value ?? '').trim().toLowerCase();
  if (!normalized) return {key: 'columbia', isDefault: true};
  return {key: ALIASES[normalized] ?? null, isDefault: false};
}

export function resolveBrandKey(brandValue, brandOverride) {
  if (BRANDS.some((b) => b.key === brandOverride)) return brandOverride;
  return mapBrand(brandValue).key;
}

`airtable-extension/frontend/lib/airtableData.js`:
```js
export const TABLES = {requisitions: 'Master Tracker - All TA', guides: 'Interview Guides'};

export const REQ_FIELDS = {
  positionTitle: 'Position Title',
  reqNumber: 'Req #',
  brand: 'Brand',
  hiringManager: 'Hiring Manager',
  format: 'Panel Interview Format',
  panelistCount: '#of Panelists',
};

export const GUIDE_FIELDS = {
  name: 'Guide Name',
  requisition: 'Requisition',
  round: 'Interview Round',
  panelists: 'Panelists',
  selections: 'Selections',
  file: 'Guide File',
  lastGenerated: 'Last Generated',
  generatedBy: 'Generated By',
};

export const ROUNDS = ['Panel', 'Second Panel', 'Final', 'Other'];

export function readRequisition(record) {
  const text = (name) => record.getCellValueAsString(name).trim();
  return {
    id: record.id,
    positionTitle: text(REQ_FIELDS.positionTitle),
    reqNumber: text(REQ_FIELDS.reqNumber),
    brand: text(REQ_FIELDS.brand),
    hiringManager: text(REQ_FIELDS.hiringManager),
    format: text(REQ_FIELDS.format),
    panelistCount: Number(record.getCellValue(REQ_FIELDS.panelistCount)) || 0,
  };
}

export function readGuide(record) {
  const links = record.getCellValue(GUIDE_FIELDS.requisition) ?? [];
  return {
    id: record.id,
    name: record.getCellValueAsString(GUIDE_FIELDS.name),
    requisitionId: links[0]?.id ?? null,
    round: record.getCellValue(GUIDE_FIELDS.round)?.name ?? '',
    panelistsText: record.getCellValueAsString(GUIDE_FIELDS.panelists),
    selectionsText: record.getCellValueAsString(GUIDE_FIELDS.selections),
    files: record.getCellValue(GUIDE_FIELDS.file) ?? [],
    lastGenerated: record.getCellValueAsString(GUIDE_FIELDS.lastGenerated),
    createdTime: record.createdTime ? new Date(record.createdTime).getTime() : 0,
  };
}

export function newGuideFields({name, requisitionId, round}) {
  return {
    [GUIDE_FIELDS.name]: name,
    [GUIDE_FIELDS.requisition]: [{id: requisitionId}],
    [GUIDE_FIELDS.round]: {name: round},
  };
}

export function savePicksFields({panelistsText, selectionsText}) {
  return {[GUIDE_FIELDS.panelists]: panelistsText, [GUIDE_FIELDS.selections]: selectionsText};
}

export function generatedFields({files, userId, at}) {
  return {
    [GUIDE_FIELDS.file]: files,
    [GUIDE_FIELDS.lastGenerated]: at.toISOString(),
    [GUIDE_FIELDS.generatedBy]: {id: userId},
  };
}

import {isKnownQuestion} from './questionBank.js';

export const SELECTIONS_VERSION = 1;
const UNREADABLE = 'Saved picks could not be read and were reset.';
const UNSUPPORTED = 'Saved picks are in an unsupported format and were reset.';

export function emptySelections() {
  return {v: SELECTIONS_VERSION, brandOverride: null, competencies: []};
}

export function serializeSelections(selections) {
  return JSON.stringify(selections);
}

const strings = (value) => (Array.isArray(value) ? value.filter((s) => typeof s === 'string') : []);

function normalizeCompetency(raw) {
  const questions = strings(raw.questions);
  return {
    name: raw.name,
    panelist: typeof raw.panelist === 'string' ? raw.panelist : '',
    questions: questions.filter((q) => isKnownQuestion(raw.name, q)),
    customQuestions: [...strings(raw.customQuestions), ...questions.filter((q) => !isKnownQuestion(raw.name, q))],
  };
}

export function parseSelections(text) {
  if (!text || !text.trim()) return {selections: emptySelections(), warning: null};
  let raw;
  try {
    raw = JSON.parse(text);
  } catch {
    return {selections: emptySelections(), warning: UNREADABLE};
  }
  if (!raw || raw.v !== SELECTIONS_VERSION || !Array.isArray(raw.competencies)) {
    return {selections: emptySelections(), warning: UNSUPPORTED};
  }
  const competencies = raw.competencies
    .filter((c) => c && typeof c.name === 'string')
    .map(normalizeCompetency);
  const brandOverride = typeof raw.brandOverride === 'string' ? raw.brandOverride : null;
  return {selections: {v: SELECTIONS_VERSION, brandOverride, competencies}, warning: null};
}

function updateCompetency(selections, name, update) {
  return {
    ...selections,
    competencies: selections.competencies.map((c) => (c.name === name ? update(c) : c)),
  };
}

export function toggleCompetency(selections, name) {
  const exists = selections.competencies.some((c) => c.name === name);
  const competencies = exists
    ? selections.competencies.filter((c) => c.name !== name)
    : [...selections.competencies, {name, panelist: '', questions: [], customQuestions: []}];
  return {...selections, competencies};
}

export function toggleQuestion(selections, name, text) {
  return updateCompetency(selections, name, (c) => ({
    ...c,
    questions: c.questions.includes(text) ? c.questions.filter((q) => q !== text) : [...c.questions, text],
  }));
}

export function setPanelist(selections, name, panelist) {
  return updateCompetency(selections, name, (c) => ({...c, panelist}));
}

export function addCustomQuestion(selections, name, text) {
  const trimmed = text.trim();
  if (!trimmed) return selections;
  return updateCompetency(selections, name, (c) => ({...c, customQuestions: [...c.customQuestions, trimmed]}));
}

export function removeCustomQuestion(selections, name, index) {
  return updateCompetency(selections, name, (c) => ({
    ...c,
    customQuestions: c.customQuestions.filter((_, i) => i !== index),
  }));
}

export function setBrandOverride(selections, key) {
  return {...selections, brandOverride: key};
}
```

export function findProblems({panelists, selections, brandKey}) {
  const named = panelists.map((p) => p.trim()).filter(Boolean);
  const problems = [];
  if (!brandKey) problems.push('Pick a brand template.');
  if (!named.length) problems.push('Add at least one panelist.');
  if (!selections.competencies.length) problems.push('Pick at least one competency.');
  for (const c of selections.competencies) {
    if (!c.questions.length && !c.customQuestions.length) problems.push(`${c.name}: pick at least one question.`);
    if (!named.includes(c.panelist)) problems.push(`${c.name}: assign a panelist.`);
  }
  return problems;
}

const UNSAFE = /[\\/:*?"<>|\u0000-\u001f]/g;
const MAX_TITLE = 120;

function clean(text) {
  return (text ?? '').replace(UNSAFE, '').replace(/\s+/g, ' ').trim().slice(0, MAX_TITLE).trim();

const norm = (value) => (value ?? '').toString().toLowerCase().trim();

export function filterRequisitions(reqs, query, limit = 20) {
  const q = norm(query);
  if (!q) return [];
  return reqs
    .filter((r) => norm(r.positionTitle).includes(q) || norm(r.reqNumber).includes(q))
    .slice(0, limit);
}

export function filterGuides(guides, query) {
  const q = norm(query);
  const newestFirst = [...guides].sort((a, b) => b.createdTime - a.createdTime);
  if (!q) return newestFirst;
  return newestFirst.filter((g) => [g.name, g.positionTitle, g.reqNumber].some((v) => norm(v).includes(q)));
}

export const DOCX_TYPE = 'application/vnd.openxmlformats-officedocument.wordprocessingml.document';
const RETRYABLE = new Set([502, 503, 504]);

export class FileDropError extends Error {}

const defaultSleep = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

export function createFileDropClient({
  baseUrl, fetchImpl = (...args) => fetch(...args), sleep = defaultSleep, now = () => Date.now(), maxWaitMs = 60_000,
}) {
  async function withRetry(request) {
    const deadline = now() + maxWaitMs;
    let delay = 1000;
    for (;;) {
      let response = null;
      try {
        response = await request();
        if (!RETRYABLE.has(response.status)) return response;
      } catch {
        response = null;
      }
      if (now() + delay > deadline) {
        throw new FileDropError('The file service did not respond. Try again in a minute.');
      }
      await sleep(delay);
      delay = Math.min(delay * 2, 8000);
    }
  }

  return {
    async wake() {
      try {
        await fetchImpl(`${baseUrl}/health`);
        return true;
      } catch {
        return false;
      }
    },
    async upload(bytes, filename) {
      const response = await withRetry(() => fetchImpl(`${baseUrl}/files?filename=${encodeURIComponent(filename)}`, {
        method: 'POST',
        headers: {'Content-Type': DOCX_TYPE},
        body: bytes,
      }));
      const body = await response.json().catch(() => ({}));
      if (!response.ok || !body.url) throw new FileDropError(body.error || `Upload failed (${response.status}).`);
      return body.url;
    },
  };
}

import {findProblems} from './validation.js';
import {guideFileName} from './fileName.js';

/**
 * Save picks → build .docx → upload → append attachment. Any failure after the build
 * returns the bytes so the UI can offer a download instead.
 */
export async function generateGuide({input, deps}) {
  const {header, panelists, selections, existingFiles} = input;
  const problems = findProblems({panelists, selections, brandKey: header.brandKey});
  if (problems.length) return {status: 'invalid', problems};

  const filename = guideFileName(header.positionTitle, header.round);
  await deps.savePicks({panelists, selections});
  const bytes = await deps.buildDocx({header, panelists, selections});
  try {
    const url = await deps.upload(bytes, filename);
    await deps.saveGenerated([...existingFiles, {url, filename}]);
    return {status: 'attached', filename};
  } catch (err) {
    return {status: 'download', filename, bytes, error: err.message};
  }
}

import {BRANDS, mapBrand, resolveBrandKey} from '../lib/brand.js';

import {
  toggleCompetency, toggleQuestion, setPanelist, addCustomQuestion, removeCustomQuestion, setBrandOverride,
} from '../lib/selections.js';
import {PanelistsEditor} from './PanelistsEditor.jsx';
import {CompetencyPicker} from './CompetencyPicker.jsx';
import {QuestionPicker} from './QuestionPicker.jsx';
import {GenerateBar} from './GenerateBar.jsx';

function BrandLine({requisition, selections, onOverride}) {
  const mapped = mapBrand(requisition.brand);
  if (mapped.key) {
    const label = BRANDS.find((b) => b.key === mapped.key).label;
    return <span>{label}{mapped.isDefault ? ' (default)' : ''}</span>;
  }
  return (
    <span>
      <label htmlFor="gb-brand">Brand template</label>
      <select id="gb-brand" value={selections.brandOverride ?? ''} onChange={(e) => onOverride(e.target.value || null)}>
        <option value="">Choose… (Brand is "{requisition.brand}")</option>
        {BRANDS.map((b) => <option key={b.key} value={b.key}>{b.label}</option>)}
      </select>
    </span>
  );
}

export function BuilderScreen({requisition, guide, initialPanelists, initialSelections, warning, onBack, onGenerate}) {
  const [panelists, setPanelists] = useState(initialPanelists);
  const [selections, setSelections] = useState(initialSelections);
  const [busy, setBusy] = useState(false);
  const [result, setResult] = useState(null);
  const running = useRef(false);
  const brandKey = resolveBrandKey(requisition.brand, selections.brandOverride);
  const problems = findProblems({panelists, selections, brandKey});
  const edit = (fn) => (...args) => { setResult(null); setSelections((s) => fn(s, ...args)); };

  const generate = async () => {
    if (running.current) return;
    running.current = true;
    setBusy(true);
    try {
      setResult(await onGenerate({panelists, selections, brandKey}));
    } catch (err) {
      setResult({status: 'download', filename: '', bytes: null, error: err.message});
    } finally {
      running.current = false;
      setBusy(false);
    }
  };

  return (
    <div>
      <button type="button" onClick={onBack}>← Back to guides</button>
      {warning && <p role="status" className="problems">{warning}</p>}
      <section className="card">
        <h2>{guide.name}</h2>
        <div><strong>{requisition.positionTitle}</strong></div>
        <div className="muted">Req # {requisition.reqNumber} · {guide.round} · {requisition.format} · Hiring manager: {requisition.hiringManager}</div>
        <div>Brand: <BrandLine requisition={requisition} selections={selections} onOverride={edit(setBrandOverride)} /></div>
      </section>
      <PanelistsEditor panelists={panelists} onChange={(next) => { setResult(null); setPanelists(next); }} />
      <CompetencyPicker selections={selections} onToggle={edit(toggleCompetency)} />
      <QuestionPicker selections={selections} panelists={panelists}
        onToggleQuestion={edit(toggleQuestion)} onSetPanelist={edit(setPanelist)}
        onAddCustom={edit(addCustomQuestion)} onRemoveCustom={edit(removeCustomQuestion)} />
      <GenerateBar problems={problems} busy={busy} result={result} onGenerate={generate}
        onCopy={() => navigator.clipboard?.writeText(copyQuestionsText(selections))} />
    </div>
  );
}

  const guideRecords = useRecords(guideTable);
  const {searchParams, setSearchParamsAsync} = useSearchParams();
  const [notice, setNotice] = useState(null);

  useEffect(() => { fileDrop.wake(); }, []);

  const requisitions = useMemo(() => (reqRecords ?? []).map(readRequisition), [reqRecords]);
  const reqById = useMemo(() => new Map(requisitions.map((r) => [r.id, r])), [requisitions]);
  const guides = useMemo(() => (guideRecords ?? []).map(readGuide), [guideRecords]);
  const guideRows = guides.map((g) => ({...g, positionTitle: reqById.get(g.requisitionId)?.positionTitle ?? '', reqNumber: reqById.get(g.requisitionId)?.reqNumber ?? ''}));
  const guide = searchParams.guide ? guides.find((g) => g.id === searchParams.guide) ?? null : null;
  const guideMissing = Boolean(searchParams.guide && guideRecords && !guide);

  useEffect(() => {
    if (!guideMissing) return;
    setNotice('That guide no longer exists.');
    setSearchParamsAsync({});
  }, [guideMissing, setSearchParamsAsync]);

  if (!reqTable) return <MissingSetup what={`the "${TABLES.requisitions}" table`} />;
  if (!guideTable) return <MissingSetup what={`the "${TABLES.guides}" table`} />;

  const openGuide = (id) => { setNotice(null); setSearchParamsAsync({guide: id}); };
  const backToStart = () => setSearchParamsAsync({});
  const createGuide = async ({requisitionId, round, name}) => {
    const id = await guideTable.createRecordAsync(newGuideFields({name, requisitionId, round}));
    openGuide(id);
  };

  if (!guide) {
    return <StartScreen requisitions={requisitions} guides={guideRows} notice={notice} onCreate={createGuide} onOpen={openGuide} />;
  }

  const requisition = reqById.get(guide.requisitionId);
  if (!requisition) return <BackWithMessage onBack={backToStart} text="This guide isn't linked to a requisition. Link one in the record, then reopen it." />;
  if (!requisition.positionTitle) return <BackWithMessage onBack={backToStart} text="The linked requisition has no Position Title. Add one in Master Tracker, then reopen this guide." />;

  const {selections, warning} = parseSelections(guide.selectionsText);
  const onGenerate = ({panelists, selections: picks, brandKey}) => generateGuide({
    input: {header: {...requisition, round: guide.round, brandKey}, panelists, selections: picks, existingFiles: guide.files},
    deps: {
      savePicks: ({panelists: p, selections: s}) => guideTable.updateRecordAsync(guide.id, savePicksFields({panelistsText: formatPanelists(p), selectionsText: serializeSelections(s)})),
      buildDocx: buildGuideDocx,
      upload: fileDrop.upload,
      saveGenerated: (files) => guideTable.updateRecordAsync(guide.id, generatedFields({files, userId: session.currentUser.id, at: new Date()})),
    },
  });

  return (
    <BuilderScreen key={guide.id} requisition={requisition} guide={guide}
      initialPanelists={initialPanelists(guide.panelistsText, requisition.panelistCount)}
      initialSelections={selections} warning={warning} onBack={backToStart} onGenerate={onGenerate} />
  );
}

function BackWithMessage({onBack, text}) {
  return (
    <div>
      <button type="button" onClick={onBack}>← Back to guides</button>
      <p className="problems">{text}</p>
    </div>
  );
}
